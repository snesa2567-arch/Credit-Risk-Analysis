# Credit Risk Analysis & Loan Behavior Insights

## Overview

This project focuses on analyzing customer loan and financial data to identify factors affecting loan approvals, repayment behavior, and default risk. The analysis helps in understanding customer credit patterns and supports data-driven financial risk assessment.

---

## Objectives

* Analyze loan approval and repayment behavior
* Identify high-risk customer segments
* Explore factors influencing default risk
* Perform data cleaning and exploratory data analysis
* Generate actionable business insights from financial data

---

* Python
* Pandas
* NumPy

* Seaborn
* SQL
* Scikit-learn
* Jupyter Notebook

## Project Workflow

1. Data Collection
2. Data Cleaning & Preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature Engineering
5. Risk Analysis & Visualization
6. Insight Generation

## Key Features

* Large-scale loan data analysis
* Missing value handling
* Customer segmentation
* Financial risk analysis
* Business-oriented visualizations
* Insight-driven reporting

---

## Key Insights

* Identified customer groups with higher default probability
* Analyzed relationships between income, credit history, and loan repayment
* Explored patterns affecting loan approval decisions
* Detected major financial risk indicators
